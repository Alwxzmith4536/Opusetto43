# Far Lands Feud

Claude vs ChatGPT: a one-minute horrorcore battle track set in the Far Lands, the broken
terrain past X 12,550,821 in old Minecraft. It comes with vocals, cover art and an animated
music video. Everything in this folder is generated by code: there are no samples, stock
loops or downloaded images.

| File | What it is |
| --- | --- |
| `index.html` | The player: a live WebGL 2 voxel flythrough, karaoke lyrics, voice on/off (instrumental) and a clickable lyric sheet. Serve the folder (`python3 -m http.server`) and open it. |
| `media/far-lands-feud.mp4` | The rendered music video, 1280×720, 30 fps, 1:00 |
| `media/far-lands-feud.mp3` | Full mix, 192 kbps |
| `media/far-lands-feud-instrumental.mp3` | Same master without vocals |
| `media/cover.jpg`, `media/poster.jpg` | Square cover art and a 16:9 poster frame |
| `src/build_track.py` | Synthesizes the beat and score, sings the lyrics with Kokoro TTS, mixes, masters, and writes the timeline into `index.html` |
| `src/render_video.mjs` | Renders the video frame by frame in headless Chromium and muxes it with ffmpeg |
| `src/check_vocals.py` | Transcribes each bar with Whisper to check that the words survive the mix |

## The track

80 BPM in E minor, looping i–♭II–iv–V (Em, F, Am, B). Twenty bars of 3 seconds each.

| Time | Section | Who |
| --- | --- | --- |
| 0:00 | Intro: heartbeat, wind, a broken music box | Narrator (whisper) |
| 0:06 | Verse I | Claude |
| 0:18 | Verse II | ChatGPT |
| 0:30 | Hook | Both, trading the lead line by line |
| 0:42 | Face-off | Alternating lines |
| 0:54 | Outro: the world dissolves, then a tape stop | Narrator |

- **Voices:** Kokoro v1.0 (`bf_emma` for Claude, `am_fenrir` for ChatGPT, `af_nicole` whispering). Each line is time-fitted to its bar with Rubber Band. Octave-down "demon" doubles and noise-excited whisper layers sit underneath.
- **Instruments:** 808s with glides, kick, clap, trap hat rolls, and a tape-worn music box that is Claude's instrument. ChatGPT's is a bit-crushed chip arpeggio. There is also a formant choir, an FM church bell, a drone, wind and static, plus risers, stutter glitches and a final tape stop.
- **Mix check:** Whisper `base.en` transcribes the full mix at about 12% word error. Most of the misses are accent spellings, such as "Four lands" for "Far Lands".

## Rebuilding

```sh
pip install numpy scipy soundfile kokoro-onnx
# kokoro-v1.0.onnx and voices-v1.0.bin from the kokoro-onnx GitHub releases (model-files-v1.0)
python3 src/build_track.py --models ~/models/kokoro      # needs ffmpeg built with librubberband
node src/render_video.mjs --audio build/far-lands-feud.wav
node src/render_video.mjs --poster
```

The renderer needs Playwright's Chromium (WebGL 2, software rendering is fine) and ffmpeg
with libx264. The video takes about half an hour on four CPU cores.
