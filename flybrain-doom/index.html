    How the test decides

    Each fly has its own random Kenyon-cell wiring. Half the flies are healed by blue orbs and half by green, so any innate color bias cancels out. Every condition runs the same flies in the same worlds. A condition learns if its preference for the healing color is above zero (two-sided permutation test, p<0.05). It re-learns if, after the colors swap, it first prefers the old color and then the new one.
